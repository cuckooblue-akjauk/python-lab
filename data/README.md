# Common datasets used in Python experiments

This folder contains a few small, public-domain-style sample datasets that are useful for quick experiments.

- `iris.csv`: classic flower dataset, commonly used for classification examples.
- `titanic.csv`: well-known survival prediction dataset used in ML and exploratory analysis.
- `sample_input.json`: lightweight JSON input for prompt or config-style experiments.

These files are intentionally small enough for local experimentation and teaching.
